# 手算金标准

`flat.json`：0 初值，每期开始投入100，价格恒10，无费用。
任意合法现金/资产分配的终值300、利润0、TWR0、回撤0。

`hand_fees.json` 配合默认 DCA：

|日期|投入|价格|买入股数|名义金额|费用|现金|累计股数|终值|本期收益|
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
|2024-02-01|102|10|10|100|2|0|10|100|100/102−1|
|2024-03-01|102|20|5|100|2|0|15|300|300/202−1|

累计投入204，利润96，TWR = (100/102)×(300/202)−1。
第一笔费用造成单位财富回撤2/102。不能用300/204−1代替TWR。
该案例的现金流本身不包含策略预期；DCA 的独立包测试指定以上金标准。
