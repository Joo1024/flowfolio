已修复并保留回归覆盖的真实差异：

1. 精确预算经过二进制浮点相减后成为微小负数，导致 Backtrader Margin 拒绝。
   通过数值边界传入十进制标量，仍使用原生 broker 成交与记账。
2. 原生汇总成交价对单次成交做乘除后出现尾差。输出改为读取原生执行 bit 的价格，
   不修改案例价格或放宽容差。

金额/股数绝对容差始终为1e-7，收益为1e-10；费用和执行价严格相等。
没有通过调整指标公式、隐藏成交或扩大容差制造一致。

原有114项测试不能覆盖全部协议边界，审查反例已经纳入回归；本记录只声明已验证
范围，不把跨后端一致当作充分的正确性证明。框架和三个策略版本已更新为0.1.1，
避免将不同实现行为记录为同一版本。

测试输出包含 Backtrader 在 Python 3.12 的 datetime.utcnow 弃用提示；它们来自上游
事件循环计时，不是金融验证失败。CI 配置覆盖 Python 3.11、3.12、3.13；
本记录的本地实测范围只声明 Python 3.12.14，其他版本以实际 CI 状态为准。

复现命令见 README；测试产物使用仓库外目录。测试验证实现与协议一致性，
不证明真实投资收益或流动性假设成立。
